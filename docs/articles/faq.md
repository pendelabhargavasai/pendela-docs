# FAQ

Frequently asked questions.

## General


### Where can I get support?

You can:
- Open an issue on [GitHub](https://github.com/pendelabhargavasai/pendela-docs)

## Technical

### Which browsers are supported?

Pendela HomeLabs Docs supports all modern browsers including:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### Does it work on mobile?

Yes, Pendela HomeLabs Docs is fully responsive and works on all screen sizes.

---

## Troubleshooting

### Something isn't working — what do I do?

1. Check you're on the latest version
2. Clear your browser cache
3. Open an issue on GitHub if the problem persists
